### 📂 Highlighted Projects

* 🌌 **[NBody](https://github.com/Lennydouzb/NBody):** A GPU computing program using **CUDA** and Newton's law of universal gravitation to simulate particle interactions in an empty space, with real-time rendering via **OpenGL**.
* 🔥 **[HeatDissipation](https://github.com/Lennydouzb/heatDissipation):** A GPU computing program that simulates 1D heat dissipation between two elements with varying thermal conductivities and volumetric capacities inside a cryostat, utilizing Laplacian discretization.
* 🧊 **[scop](https://github.com/Lennydouzb/scop):** A 3D object rendering application developed in C++11 using **OpenGL** and a personal mathematics/matrix computation library.
* 🐳 **[Inception](https://github.com/Lennydouzb/inception):** A secure and isolated multi-container infrastructure, deployed from scratch via **Docker Compose** (Nginx, MariaDB, WordPress, Redis, etc.).
* 💬 **[ft_irc](https://github.com/Lennydouzb/ft_irc):** A fully functional Internet Relay Chat (IRC) server written in C++, complying with the RFC 2812 protocol specifications.

> **⚙️ 42 Systems Projects:** Developed a command-line interpreter **[(Minishell)](https://github.com/Lennydouzb/minishell)**, built an inter-process communication system using UNIX signals **[(minitalk)](https://github.com/Lennydouzb/minitalk)**, and managed memory concurrency using threads and mutexes **[(Philosophers)](https://github.com/Lennydouzb/Philosopher)**.
